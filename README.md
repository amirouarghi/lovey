# For Ilhem — A Secret Garden

An animated ASCII-art gift: a name that opens into a purple garden with flowers and kitties.

## Structure

```
ilhem-garden/
├── index.html      page markup
├── css/style.css   styles
├── js/main.js      animation, audio and interaction
└── .vscode/        editor settings
```

## Run it in VS Code

1. `File > Open Folder...` and choose `ilhem-garden`.
2. Install the **Live Server** extension (Ritwick Dey). Recommended extensions are suggested automatically.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also just double-click `index.html` to open it in a browser.

## Personalize

Edit `GIFT_CONFIG` at the top of `js/main.js` to change the note text and finale message.
The name drawn in ASCII art is `ILHEM_ART` in the same file.
